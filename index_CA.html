Information Processing

Understanding the Data → Information → Knowledge hierarchy is essential for answering high-order evaluation questions:

Data — unorganised raw facts. Information — data processed into context. Knowledge — analytical application of information to identify trends or make informed judgements.

Data Validation vs. Data Verification

To combat Garbage In, Garbage Out (GIGO): validation ensures data is sensible; verification ensures it is correct against the source.

MethodTypeSpecific RoleRole in Reducing GIGO
Presence CheckValidationEnsures required fields are not left blank.Prevents critical missing records (e.g., Student Name).
Range CheckValidationEnsures data falls within logical boundaries.Prevents impossible entries (e.g., Age > 120).
Format CheckValidationEnsures data follows a specific pattern.Detects structural errors (e.g., missing "@" in email).
Check DigitValidationUses an algorithm to verify digits.Detects transcription or transposition errors in IDs.
Double EntryVerificationRequires entering the same data twice.Reduces human typing errors (e.g., new passwords).
ProofreadingVerificationHuman comparison against source documents.Catches subtle errors that algorithms might miss.

Data Representation

Binary and hexadecimal systems form the language of hardware communication and memory addressing. Hexadecimal is valued for representing large binary strings (like MAC addresses) concisely.

Two's Complement Representation

To represent negative integers in a fixed-bit system:

  1. Start with the positive binary. Example: for −3 in 8-bit → 00000011
  2. Invert all bits. → 11111100
  3. Add 1. → 11111101 ✓
So What? — Overflow Errors An overflow error occurs when a calculation result exceeds the maximum range of the bit-system, causing the sign bit to flip incorrectly. This leads to critical software crashes or logic corruption because the computer cannot "fit" the result into the allocated memory.

Computer System Fundamentals

The Fetch-Decode-Execute (FDE) cycle is the heartbeat of machine organisation. The CPU fetches instructions from RAM, decodes the machine code, and executes the task — repeating this billions of times per second (Clock Rate).

Device Evaluation: Desktop vs. Smartphone

Device A — Desktop

Features a standalone display card (dedicated GPU).

So What? A dedicated GPU provides superior graphical performance for rendering 4K video or high-end simulations by offloading math-heavy tasks from the CPU.

Device B — Smartphone

Prioritises Flash memory and integrated units.

So What? Flash memory offers higher data transfer rates and lower power consumption, critical for extending battery life and portability.

Hardware Improvements & The Software Link

ComponentImprovementImpact
RAM CapacityLarger capacityMore applications reside in memory simultaneously, reducing slow virtual memory swaps.
CPU Clock RateHigher rateMore FDE cycles per second, directly increasing system throughput.
Driver ProgramsLatest versionNot just for speed — specifically fixes bugs and ensures compatibility with newer OS updates.

Internet & Cybersecurity

As we shift from IPv4 (32-bit) to IPv6 (128-bit) to accommodate the Internet of Things (IoT), technical precision in bandwidth and security is the key differentiator for Band 1 students.

Bandwidth Calculation — Binary Precision

⚠ Common Trap Avoid the 8-bit = 1-byte shortcut with decimal 1000. For Band 1 precision, use binary units (×1024) for file sizes when requested or implied.

Scenario: Uploading 200 photos (5 MB each) at 100 Mbps.

  1. Total Size in Bits: 200 × 5 MB × 1024 (KB) × 1024 (B) × 8 = 8,388,608,000 bits
  2. Shortest Time: 8,388,608,000 ÷ 100,000,000 bps = 83.9 seconds (3 sig. fig.)

Note: Using the decimal method (80s) may lose marks if the marker expects binary conversion for storage units.

Public Key Infrastructure (PKI): Dual Mechanisms

1 — Confidentiality

Eva uses Paul's Public Key to encrypt. Only Paul's Private Key can decrypt.

So What? Even if intercepted, the file is unreadable to anyone but Paul.

2 — Authentication / Non-Repudiation

Eva uses her own Private Key to "sign" the file. Paul uses Eva's Public Key to verify.

So What? This proves the file definitely came from Eva and was not altered in transit.

Database Management

Relational databases rely on Data Integrity to maintain reliability:

Integrity TypeRuleExample
Entity IntegrityUnique Primary Keys — no duplicates.Each student record has a unique Student ID.
Referential IntegrityForeign Keys must match existing Primary Keys.An order cannot reference a non-existent customer ID.
Domain IntegrityData must match defined types/logic.Check-in date cannot be after check-out date in a hotel system.

Master SQL Reference (Table: SS)

Basic Extraction:

SELECT CL, CNO FROM SS
WHERE SER = 'Flag selling'
  AND CL LIKE '2_'   -- '_' = exactly one character; '%' = any number

Aggregation:

SELECT CL, SUM(HR)
FROM SS
GROUP BY CL   -- Fields NOT in an aggregate function MUST be in GROUP BY

Computational Thinking & Programming

Computational Thinking rests on three pillars: Abstraction (ignoring the irrelevant), Algorithmic Thinking (the step-by-step logic), and Automation (the code).

Dry Run Guide: The "Index Trap"

⚠ Exam Trap In Python, range(0, 5) includes 0 but excludes 5 → indices 0, 1, 2, 3, 4 only.

Example — reversing an array:

for i in range(0, 5):
    s2[4-i] = s1[i]
iOperationValue assigned
0s2[4] = s1[0]'S'
1s2[3] = s1[1]'T'
2s2[2] = s1[2]'E'
3s2[1] = s1[3]'A'
4s2[0] = s1[4]'M'

Result: s2 = ['M', 'A', 'E', 'T', 'S']

Check Digit Validation: Username '4B115'

Algorithm: S = F + N (Form + Number). If Class is 'B', then S = S × 3. Check Digit D = S mod 10.

  1. F = 4, N = 11 → S = 4 + 11 = 15
  2. Class is 'B' → S = 15 × 3 = 45
  3. D = 45 mod 10 = 5
Result Username is Valid — the check digit 5 matches D. This logic detects transcription errors like typing '4A' instead of '4B'.

Professional ICT Practice: Health & Ergonomics

Professional practice requires addressing Repetitive Strain Injury (RSI). Ergonomic solutions — adjustable chairs, wrist rests, and user-friendly GUI design — are not mere comforts. They are essential measures to maintain productivity and fulfil the duty of care in an ICT environment.
